# Structured metadata projection

The repository publishes deterministic JSON-LD at `structured-data/hypotheses.jsonld` so search systems, research software and autonomous agents can discover the same public hypothesis collection without scraping presentation HTML.

## Source of truth

The JSON-LD projection is generated from the canonical public `hypotheses/{OS-TH-####}/hypothesis.json` objects and existing public evidence bindings. It is not a separate scientific record, evidence store, ranking system or publication authority.

The projection is generated by `scripts/render-structured-metadata.js`. CI runs the renderer in `--check` mode so a stale projection fails validation.

## Conservative semantics

Each hypothesis is represented as a Schema.org `CreativeWork`, not as a treatment, medical guideline, clinical recommendation or clinically validated intervention. The projection carries explicit machine-readable properties for:

- evidence stage;
- review state;
- publication class;
- scientific-review requirement;
- uncertainty level;
- contradictory-evidence status;
- research-priority meaning;
- `clinicalUse:false`;
- the research-only boundary.

Public evidence citations resolve only through existing `evidence-bindings/` records with HTTP(S) canonical source URLs.

## Standards boundary

Using Schema.org JSON-LD makes the metadata syntactically discoverable. It does not claim independent certification, indexing acceptance, external standards conformance, scientific peer review or clinical validation. Search engines and external services may interpret structured metadata differently, so the canonical EduLinked research objects remain authoritative for repository meaning.

## Privacy and authority

Do not add private source topology, private research notes, patient information, credentials, unpublished restricted evidence or private authority records to the JSON-LD projection. Only deliberately public research fields and public evidence URLs belong here.

The projection cannot transfer scientific-review, disclosure, publication or clinical-use authority.
